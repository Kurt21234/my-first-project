\#My First Git Project



A simple website built to practice Git and GitHub, including branching, Pull Requests, and the Git Flow model.



\## Pages

\- \*\*Home\*\* (`index.html`): main landing page with a navigation bar

\- \*\*Products\*\* (`products.html`): list of products

\- \*\*Contact\*\* (`contact.html`): contact form



\## Styling

All pages share `style.css`.

## Version
Release v1.0: first stable version with Home, Products, and Contact pages.



\## Workflow

Developed using Git Flow with `main`, `develop`, feature, release, and hotfix branches.
